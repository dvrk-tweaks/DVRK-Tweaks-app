# DVRK Tweaks Ultimate

Professional C#/.NET 8 WPF performance utility for Windows.

## Included
- 9 performance categories
- 135 performance switches
- DVRK branding
- ON/OFF switches only
- Apply Enabled / Reset Profile
- Admin mode
- FPS, frame-time, input, network and background-process focused settings
- Discord: https://discord.gg/sYAFfpemb

## Important
Performance settings vary by hardware, driver and game. The app uses reversible Windows settings and commands; a setting being enabled does not guarantee a higher FPS or lower ping on every PC. Network changes can affect connectivity, and service changes can disable features you use.

## Build
Load `DvrkTweaks.csproj` in Visual Studio 2022 on Windows with **Desktop development with .NET** installed. Build for x64.

The manifest requests administrator permission because many Windows performance settings require it.
